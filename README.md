# zwxdogs 的个人网站

在读博士生的个人网站，内容包括个人介绍、论文发表、开发项目和日常分享。

## 当前状态

**规划阶段**。站点尚未开始实现，目前仓库里只有调研笔记与探索地图。

## 已确定的决定

| 主题 | 决定 |
| --- | --- |
| 技术栈 | Astro，纯静态输出 |
| 托管 | EdgeOne Pages，全球可用区（不含中国大陆） |
| 域名 | 需购买自定义域名（平台二级域名对大陆访客仅 3 小时有效） |
| 语言 | 全中文，论文标题与技术名词保留英文 |
| 结构 | 首页单页可下滑：介绍 → 论文 → 项目 → 分享 |
| 不做 | RSS、站内搜索、评论、双语切换 |

完整决策记录见 [探索地图](.scratch/phd-personal-site/map.md)。
